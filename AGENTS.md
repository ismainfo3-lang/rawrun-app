# RawRun engineering instructions
This is a clean-room restart. Do not copy or modify the previous RawRun repositories or old Supabase projects.
Keep the mobile app iPhone-first, React Native/Expo/TypeScript, with a centralized RAW / FRAME design system: warm monochrome, restrained signal green, full-color natural photos. Preserve accessibility.
Use an offline-first run state machine; track only active time, pause cleanly, persist drafts and prevent duplicate sync. Background location and notification delivery require physical-device QA. Never represent foreground tracking as background-capable.
Never commit secrets, service-role keys, signing assets, personal data or .env files. Use the new backend only; test RLS with owner, friend, unrelated and anonymous contexts before beta. Keep coordinates private, private Storage buckets and short-lived authorized image access. Do not disable RLS.
Raw Moment: one per run, randomized after ten active minutes; five-minute capture window, optional postponement/skip, one retake, optional short-run capture on finish, publish only after final confirmation. Friends by mutual accepted request, default audience friends, public city only, private archive after 24 hours. No fake social activity.
Before claiming completion run typecheck, unit tests, dependency checks and native QA where applicable; report untested behavior. Commit lockfile generated by npm. Use non-destructive git operations.
